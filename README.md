# TrainingNotes

A pnpm workspace monorepo for a rehab/training tracker: an Express API,
a Postgres/Drizzle database, a React web app, a mockup sandbox, and an
Expo companion app.

- **Running locally in VS Code**: see [docs/LOCAL_DEV.md](docs/LOCAL_DEV.md).
- **Workspace structure, stack, and key commands**: see [replit.md](replit.md).
